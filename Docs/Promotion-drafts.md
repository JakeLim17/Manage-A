# 소개 글 초안

게시하지 않은 초안입니다. 실제 계정·프로젝트 이미지 대신 공개 예시 지도를 사용하세요.

## 한국어

AI로 앱을 만들었는데, 화면·서버·DB가 어떻게 연결됐는지 설명하기 어렵더라고요. 그래서 내 컴퓨터에서 프로젝트를 살펴보는 Manage-A를 만들었습니다.

프로젝트 구조를 누르면서 역할과 근거 파일을 읽고, 프로젝트별 서비스 계정·AI 사용량·운영 상태를 함께 정리합니다. 움직이는 점은 설명용이며 실제 트래픽 추적은 아닙니다.

소개 페이지에서 설치 없이 예시 지도를 체험할 수 있습니다. 현재 앱 화면은 한국어이고 영어 설치 가이드를 제공합니다. 처음 보는 사람이 어디에서 헷갈리는지 피드백을 받고 싶습니다.

https://jakelim17.github.io/Manage-A/

## 영어

I built apps with AI, but couldn't explain how the interface, server, and database connected. So I made Manage-A, a local dashboard for understanding those projects.

Explore source structure and evidence, organize service accounts by project, and check AI usage and service health. The animated map explains connections; it isn't live traffic tracing.

Try the example map without installing anything. The app UI is currently Korean, with an English setup guide available. I'd love feedback on what still feels confusing to someone new to development.

https://jakelim17.github.io/Manage-A/en/
