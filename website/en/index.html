From installation to your first map

Install Node.js 24, clone the repository, and set your project folder in .env. No npm dependency installation or build step is required.

git clone https://github.com/JakeLim17/Manage-A.git
cd Manage-A
cp .env.example .env
# Set PROJECT_ROOT in .env to your project folder
npm start

Know the boundaries

Source analysis is not live request tracing. Automatic AI limit reporting varies by provider and account; Cursor may require CSV or manual entry. Discovering a project does not authenticate its services. The app interface is currently Korean; an English setup guide is available.
