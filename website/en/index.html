From installation to your first map

Install Node.js 24, clone the repository, and set your project folder in .env. No npm dependency installation or build step is required.

git clone https://github.com/JakeLim17/Manage-A.git
cd Manage-A
cp .env.example .env
# Set PROJECT_ROOT in .env to your project folder
npm start
English setup guide

Getting started with project visualization

What is Manage-A?

A local project visualization dashboard for understanding how the interface, server, database, and deployment of an AI-built app fit together. Explore component roles and source-file evidence in its service map.

Do I need to publish my code or accounts?

No. The dashboard runs on your computer at 127.0.0.1 by default. This public introduction contains a fixed example only. External account and analytics connections require separate setup and permissions.

Is Claude, Codex, and Cursor usage connected automatically?

Support varies by provider, account, and plan. Subscription limits and API costs are separate; Cursor may require CSV or manual entry. See the English setup guide for installation and connection details.

Know the boundaries

Source analysis is not live request tracing. Automatic AI limit reporting varies by provider and account; Cursor may require CSV or manual entry. Discovering a project does not authenticate its services. Switch between English and Korean in the app, including service maps, settings, and the user guide. Your project entries and original provider diagnostics are preserved.
