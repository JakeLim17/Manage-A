AI가 만든 프로젝트, 이제 내가 이해할 차례.

화면, 서버, 데이터베이스가 어떻게 연결됐는지 살펴보세요. Manage-A는 내 컴퓨터에서 프로젝트 구조와 AI 사용량, 운영 상태를 확인하는 대시보드입니다.

사용자가 보고 누르는 곳

버튼과 입력창, 결과 화면입니다. 예를 들어 메모를 저장하면 화면이 서버에 요청을 보냅니다.

실제 앱은 분석된 파일과 근거를 표시하며, 추정한 연결은 따로 구분합니다.

화면 → 서버 → 데이터베이스는 요청 예시이고, 배포는 실행 환경입니다. 실제 호출량을 보여주지 않습니다.

코드를 몰라도, 질문할 수 있게.

어디와 연결됐지?

화면·API·저장소의 구조와 근거 파일을 확인합니다.

어느 계정이었지?

프로젝트별 GitHub·Vercel·Supabase·Cloudflare 연결 정보를 정리합니다.

얼마나 남았지?

AI 구독 한도와 API 비용을 구분합니다. 서비스·플랜에 따라 연결 방식이 다릅니다.

잘 돌아가고 있나?

로컬 서버와 운영 사이트를 나눠 점검하고, GA4·Search Console 통계를 연결합니다.

내 프로젝트는 내 컴퓨터에.

이 공개 페이지는 예시만 보여줍니다. 대시보드는 기본적으로 127.0.0.1에서 실행합니다. 프로젝트 소스를 이 소개 페이지에 업로드하지 않으며, 외부 통계는 직접 연결한 제공자의 API로 조회합니다.

설치부터 첫 지도까지

Node.js 24를 설치한 뒤 저장소를 내려받고, .env에 프로젝트 폴더를 지정하세요. 별도 npm 패키지 설치나 빌드는 필요하지 않습니다.

git clone https://github.com/JakeLim17/Manage-A.git
cd Manage-A
cp .env.example .env
#  .env에서 PROJECT_ROOT를 내 프로젝트 폴더로 수정
npm start

프로젝트 시각화, 시작 전에 궁금한 점

Manage-A는 어떤 도구인가요?

AI로 만든 앱의 화면·서버·데이터베이스·배포가 어떻게 연결되는지 이해하도록 돕는 로컬 프로젝트 시각화 대시보드입니다. 서비스 지도에서 역할과 근거 파일을 함께 살펴볼 수 있습니다.

코드나 계정을 공개해야 하나요?

아니요. 기본 대시보드는 내 컴퓨터의 127.0.0.1에서 실행하고, 이 공개 소개 페이지에는 고정 예시만 표시합니다. 외부 계정·통계 연결은 별도 설정과 권한이 필요합니다.

Claude·Codex·Cursor 사용량이 모두 자동으로 연결되나요?

제공자·계정·플랜에 따라 다릅니다. 구독 한도와 API 비용은 구분하며, Cursor는 CSV나 직접 입력이 필요할 수 있습니다. 설치와 연결 방법은 한국어 사용 가이드에서 확인하세요.

먼저 알아두세요

구조 분석은 실제 요청 추적이 아닙니다. AI 한도 자동 조회는 서비스·계정에 따라 지원 범위가 다르고, Cursor는 CSV나 직접 입력이 필요할 수 있습니다. 프로젝트를 연결했다고 모든 서비스가 자동 인증되지는 않습니다. 앱에서 한국어·영어를 전환할 수 있습니다. 서비스 지도·설정·사용설명서도 함께 바뀌며, 직접 입력한 프로젝트 정보와 제공자 원문 진단은 보존합니다.
